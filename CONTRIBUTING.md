# Contributing

Thank you for your interest in contributing to this profile repository!

## How to Contribute

1. **Fork** the repository
2. **Create a branch** for your changes: `git checkout -b feat/my-feature`
3. **Make your changes** following the guidelines below
4. **Commit** using [Conventional Commits](https://www.conventionalcommits.org/)
5. **Push** to your fork
6. **Open a Pull Request** against `main`

## Guidelines

### Commit Messages

Follow the Conventional Commits specification:

```
<type>(<scope>): <description>
```

Types: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `ci`, `chore`

### Code Quality

- Run `pre-commit run --all-files` before committing
- Ensure no secrets are exposed (gitleaks will catch them)
- Keep the README clean and well-formatted

### Pull Requests

- Use the PR template
- Describe what and why, not just how
- Link related issues
- Ensure CI passes

## Code of Conduct

Be respectful and constructive. This is a personal profile repo — keep it professional.

## Questions?

Open an issue or reach out via the contact links in the README.
