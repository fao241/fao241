# Checklist — fil rouge

> À repasser **à la fin de chaque partie**, sur son propre profil GitHub.
> Ce n'est pas grave si tout n'est pas coché au début : les parties suivantes servent à compléter.

---

## Partie 1 — Attentes des recruteurs

- [ ] Mon profil n'expose aucune donnée sensible (mot de passe, clé, token, `.env`)
- [ ] Aucune information d'infrastructure n'est visible (IP, hôte interne, service exposé)
- [ ] Les repos que je mets en avant contiennent du contenu que j'ai réellement produit
- [ ] Aucun repos mis en avant n'est un simple fork sans ajout de ma part
- [ ] Je peux expliquer et assumer tout ce que j'affiche (titre, réalisation, certification)

## Partie 2 — Profil GitHub

- [ ] J'ai un repo **public** nommé exactement comme mon pseudo
- [ ] Mon `README` s'affiche bien sur ma page de profil
- [ ] J'ai choisi un **positionnement** (angle métier)
- [ ] Mon **header** indique mon nom + mon positionnement
- [ ] Mon **`whoami`** tient en 3 lignes (qui je suis + ce que je cherche)
- [ ] Ma **stack** liste une dizaine de technos que je maîtrise
- [ ] Je mets en avant **au maximum 3 projets**
- [ ] J'ai un lien vers une **preuve de pratique** (HackTheBox, Root-Me, blog…)
- [ ] Mes **contacts** sont à jour (LinkedIn, mail)
- [ ] Ma mise en forme est cohérente, sans surcharge
- [ ] Aucun lien mort

## Partie 3 — Bonnes pratiques Git / GitHub

- [ ] Mes **commits** sont ciblés (une feature / un fix / un refacto à la fois)
- [ ] Mes messages de commit suivent une **convention** (`type(scope): nom` + description)
- [ ] J'utilise une **branche dédiée** avant de revenir sur `main` via une **PR**
- [ ] J'ai posé au moins un **tag** de version
- [ ] Mon **`.gitignore`** est configuré **et commité**
- [ ] Mon repo contient un **`README.md`** clair
- [ ] J'ai au moins un **hook pre-commit** qui tourne (ex. scan de secrets)
- [ ] J'ai ajouté un **`CHANGELOG.md`**
- [ ] J'ai ajouté un **`AGENTS.md`**
- [ ] J'ai un **`PULL_REQUEST_TEMPLATE.md`** et/ou un **`CONTRIBUTING.md`**
- [ ] **Dependabot** est activé sur le repo
- [ ] (bonus) J'ai une **CI GitHub Actions**

## Partie 4 — Portfolio

- [ ] J'ai créé un repo pour mon portfolio
- [ ] J'ai activé **GitHub Pages** (`Settings > Pages` → branche `main`)
- [ ] Ma **page d'accueil** est accessible en ligne
- [ ] J'ai rédigé **au moins un article** (write-up, récit, retour projet)
- [ ] Mes **informations sensibles** sont caviardées
- [ ] (si template) j'ai utilisé un template clé en main type **Jekyll Now**

## Partie 6 — Recherche d'alternance

- [ ] J'ai défini mon **angle** (OSINT / Pentest / Blue team / Agentic Security)
- [ ] J'ai écrit un **pitch de 2-3 phrases** (qui je suis, ma situation, ce que je cherche)
- [ ] J'ai identifié mes **preuves sociales** (projets, challenges, école)
- [ ] J'ai repéré au moins une **piste** (job dating, meetup, salon)
- [ ] Mon **profil GitHub est repris dans mon CV** (lien cliquable et/ou QR code)
- [ ] (bonus) ma **puce NFC** pointe vers mon profil GitHub

## Partie 5 — Projet démonstrateur

- [ ] J'ai publié un **projet perso** sur GitHub
- [ ] Son **README** explique à quoi il sert et comment l'utiliser
- [ ] Le repo respecte la checklist de la **partie 3** (commits, `.gitignore`, hooks, etc.)
- [ ] Je peux le **présenter à l'oral**
